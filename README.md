## Sayari Infrastructure Technical challenge

Congratulations for making it to the technical challenge step of the Sayari Infrastructure interview process! For this technical challenge, you will complete two modules and present your solution in a live collaboration session with engineers you will be working with at Sayari.

### Module 1 - This Project Has Got Problems

There are a number of issues with this project.  The goal is to identify and fix as many of the problems as you can and get it to deploy to kubernetes successfully.

If you don't have a kubernetes cluster handy, you can deploy one locally with [kind](https://kind.sigs.k8s.io/).

Please don't take this as a reflection of the work we do here.  We promise it's not this bad. The goal here is to have you show us that you can debug stuff you didn't write and get it working when needed.

### Module 2 - Run This at Scale

Document via a text editor or via your favorite diagramming software how you would deploy this application to production and at scale.
